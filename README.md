# Exercícios Práticos em Java

Este repositório contém uma coleção de **exercícios práticos** desenvolvidos em **Java**, utilizando o **Visual Studio Code** como ambiente de desenvolvimento. Aqui você encontrará desafios focados no aprendizado e na aplicação de conceitos fundamentais e avançados da programação orientada a objetos, estrutura de dados, algoritmos e muito mais.

## Estrutura do Repositório

- **Exercícios**: Uma série de desafios e implementações em **Java**, abrangendo tópicos como:
  - **Programação Orientada a Objetos (OOP)**: Classes, objetos, herança, polimorfismo, etc.
  - **Estruturas de Dados**: Listas, pilhas, filas, mapas, e arrays.
  - **Algoritmos**: Ordenação, busca e manipulação de dados.
  - **Tratamento de Exceções**: Como lidar com erros e falhas no código.

- **Ferramentas Utilizadas**:
  - **Java 8+**: A versão do Java utilizada para os exercícios.
  - **Visual Studio Code**: IDE preferida para escrever e testar os códigos Java.

## Tecnologias e Ferramentas

- **Java**: Linguagem de programação orientada a objetos usada para todos os exercícios.
- **Visual Studio Code**: Ambiente de desenvolvimento leve e eficiente para programar em Java.
